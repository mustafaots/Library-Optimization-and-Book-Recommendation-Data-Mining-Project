# Library-Optimization-and-Book-Recommendation-Data-Mining-Project
Full Title: Data-Driven Library Optimization and Personalized Book Recommendation System
This is an academic data mining project which aims to directly apply the techniques on the data set of the ENSIA library.

The project can be summed up through 2 phases:

## Phase I:     Data Preprocessing
Cleaning the data and studying it carefully to gain more insight about the specific problem

## Phase II:    Data Mining
Using the preprocessed data in three techniques to treat the problem statement:

### Technique 1:        Clustering | Optimisation
Clustering books to optimise the library purchases and inventory housings

### Technique 2:        Clustering | Recommendation
Clustering people with relative similarity to recommend books to them

### Technique 3:        Association Rules | Recommendation
Creating association rules to create relation ships that help us recommend books to people based on their previous preferences
